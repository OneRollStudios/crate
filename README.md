# ORS Resources

Products and resources by [One Roll Studios](https://onerollstudios.com). Each
top-level folder is a self-contained product.

## Products

- **[crate/](crate/)** — **Crate**, open-source React components for the wait
  time between an AI prompt and a finished answer (the "wait states" pack).
  Ships as a shadcn registry deployed to `crate.onerollstudios.com`.
  See [crate/README.md](crate/README.md) to develop or install it, and
  [crate/design/mvp.md](crate/design/mvp.md) for the broader Crate marketplace
  brief.

## archive/

Superseded explorations kept for reference — notably **latent**, the earlier
name/prototype for Crate. Not built or deployed.
